# Experiment ledger

One row per experiment, in the order run. Numbers come from the files named in "Artifacts". Update this file every time something is run; never overwrite a past row.

Fixed unless stated: corpus = `ghg-protocol-revised.pdf` (2004 Corporate Standard, 116 pages); extraction = plain `pdftotext`; embeddings = `BAAI/bge-small-en-v1.5` (local, free); chunk overlap 20%; RRF constant 60.
